These are files that were created to create a Universal Computer Constructor
in a simulated world with things like NAND gates and Data Flip Flops.

This was created to pin down some numbers for the Memory and FLOP/S Hardware Limits to Prevent AGI? paper:
https://www.researchgate.net/publication/388398902_Memory_and_FLOPS_Hardware_limits_to_Prevent_AGI

These were created by Claude (Sonnet 5.5 mainly).

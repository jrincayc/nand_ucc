# RNDP Replicator 2 -- Hack-vN-AB quine, ROM and RAM part, no improver

A machine (Y's Hack-vN-AB CPU, 8-bit data, 15-bit address bus, 16 KB ROM, 128 B of NAND/DFF RAM built from tiles) that rebuilds
a copy of itself through the RNDP arm: PLACE every part, copy the ROM image, wire everything on a 2-layer copper grid, wire EN,
wire RUN last.  No improver (Y's M5 improver is dropped); this is the simple baseline that prices routing.

## Files
| path | role |
|---|---|
| hd/core_r7_ram.hd | readable hardware description (2,090 nodes: 2,034 NAND, 56 DFF; RAM is a RAM part with ports ram_addr/ram_we/ram_din, reads come back as ramrd0..7) |
| hd/core_r7_ram_data.asm | GENERATED by `tools/hd2asm.py` (data records in ROM) |
| tools/ref_flatten.py | reference flattener: HD -> PCB commands (dedicated-lane layout), the spec for the builder |
| tools/hd2asm.py | mechanical HD -> ROM data encoder + independent decoder |
| tools/asm.py, hd.py | assembler (trusted base), HD reader |
| src/macros.asm ram.asm builder.asm | the builder program (about 118 B RAM of 128) |
| tests/run_builder.py | runs the assembled builder on the behavioural model; compares every arm command with the reference |
| tests/validate_geometry.py | builds the reference commands in the rndp simulator; pin nets must equal the HD netlist |
| tools/make_seed.py | writes seed.build (all but RUN) and run.build |
| tests/compare_gen.py | quine check on a simulator state: child == parent shifted by DX |

## Pipeline
```
python3 tools/hd2asm.py hd/core_r7_ram.hd hd/core_r7_ram_data.asm
HACK_AB=15 python3 tools/asm.py -o out src/macros.asm src/ram.asm src/builder.asm hd/core_r7_ram_data.asm
HACK_AB=15 python3 tests/run_builder.py out hd/core_r7_ram.hd            # builder == reference commands
python3 tests/validate_geometry.py hd/core_r7_ram.hd                      # PCB nets == netlist
python3 tools/make_seed.py hd/core_r7_ram.hd out/rom.bin WORK
rndp --rom on --ram on --layers 2 --build WORK/seed.build --steps 40 --save WORK/s1.state   # held in reset
rndp --world WORK/s1.state --build WORK/run.build --steps N --dump-on-en WORK/en --save WORK/gen1.state
python3 tests/compare_gen.py WORK/gen1.state
```
